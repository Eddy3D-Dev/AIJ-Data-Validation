  RECOMMENDED inlet (this repository's choice, not the benchmark's): U(z) = u*/kappa ln((z + z0)/z0) with u* = 0.09369 m/s, z0 = 0.0003051 m fitted to the measured profile (least squares, kappa = 0.41, z = 0.02 .. 2H on AF_caseJ.csv); k = u*^2/sqrt(Cmu); epsilon = u*^3/(kappa (z + z0)). flowDir is the case's wind direction by the convention along_x (cases/J.json inflow.flow_direction).
  OpenFOAM 12 (openfoam.org) syntax. ESI OpenFOAM v2xxx: the three atmBoundaryLayerInlet* conditions and nutkAtmRoughWallFunction take the same entries there; fixedProfile is openfoam.org only (use timeVaryingMappedFixedValue or codedFixedValue).
\*---------------------------------------------------------------------------*/

{
    format      ascii;
    class       volVectorField;
    object      U;
}
dimensions      [0 1 -1 0 0 0 0];
internalField   uniform (1.4581 0 0);
boundaryField
{
    inlet
    {
        type            atmBoundaryLayerInletVelocity;
        flowDir         (1 0 0);
        zDir            (0 0 1);
        Uref            1.4581;
        Zref            0.16;
        z0              uniform 0.0003051;
        d               uniform 0;
        kappa           0.41;
        Cmu             0.09;
        value           $internalField;
    }
    outlet          { type inletOutlet; inletValue uniform (0 0 0); value $internalField; }
    ground          { type noSlip; }
    buildings       { type noSlip; }
    top             { type slip; }
    sides           { type slip; }
}
